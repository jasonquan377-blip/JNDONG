# 醬動 JN DONG

> 動起來・遇見更好的自己

醬動是一個健身 app：依照你的目標、程度、器材和時間排出每週訓練菜單，記錄每次用的重量，自動建議什麼時候該加重，並由品牌角色「花豹教練」陪你訓練。

這個專案有兩個版本：

| | 網站版（PWA） | Claude 版 |
|---|---|---|
| 檔案位置 | 這個資料夾最外層的 `index.html` 等檔案 | `claude-version/jndong-claude.html` |
| 怎麼打開 | GitHub Pages 網址，可加到手機主畫面 | 在 Claude 裡開啟的 app 連結 |
| AI 功能 | 沒有。教練分頁是引導式問答（50 題常見問題，可打字提問） | 有：AI 設計菜單、AI 花豹教練聊天、AI 週回顧 |
| 費用 | 免費 | 免費（AI 用的是開啟者自己的 Claude 額度） |
| 適合 | 分享給任何朋友，不需要帳號 | 有 Claude 帳號的人 |

## 功能

- **今天**：本週進度圓環（訓練次數、肌力分數、組數）、週曆、今天的課表。每個動作有組數 × 次數、RPE、休息時間、技術要點、重量加減按鈕和加重建議。課表包含暖身與收操，並顯示時間估算。點動作旁的「教學」可以看會動的示意圖、步驟和常見錯誤。休息日可以把這週還沒練的課表改到今天練。按「編輯動作」可以自己新增、刪除、排序動作，調整組數、次數和休息時間。
- **菜單**：設定目標（增肌、減脂、變強壯、練體力）、程度、器材（健身房、啞鈴、徒手）、自己選哪幾天練（2–6 天）、每次 30–75 分鐘、體重，按「開始排我的課表」產生一週課表。
- **教練**：花豹教練。網站版是引導式對話：點主題、點問題，或自己打字提問（50 題常見問題）；Claude 版是 AI 聊天。
- **進度**：肌力分數（腿部、臀腿後側、推、拉）、近 8 週訓練次數圖表、各動作最佳重量、訓練紀錄（可編輯刪除，有復原），以及備份匯出／匯入（網站版）。

## 常用操作

- **更新網站**：照 `docs/更新步驟.md`。記得把 `sw.js` 第 2 行的版本號加 1（例如 `jndong-v7` → `jndong-v8`），手機才會抓到新版。
- **在電腦上預覽**：直接用瀏覽器打開 `index.html` 就能看畫面和操作。要完整測試離線功能，請看 `docs/技術說明.md` 的「本機測試」。
- **修改花豹教練的問答**：改 `docs/花豹教練50題.md` 後交給 Claude，或直接在 `index.html` 裡搜尋 `const FAQ=` 修改。
- **找 Claude 幫忙修改**：把整個專案資料夾壓縮成 zip 上傳到對話，說明想改什麼即可。

## 注意事項

- 每個人的訓練紀錄只存在自己手機的瀏覽器裡，不會上傳到任何伺服器。換手機或清除瀏覽器資料前，請先在「進度」頁最下面「匯出紀錄」。
- iPhone 刪掉主畫面的 app 圖示，紀錄可能會一起被刪除。
- app 的建議僅供一般參考，不能取代醫師或物理治療師。有傷病、懷孕或慢性病，請先諮詢專業人員。
